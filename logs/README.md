# Logs do Projeto

Esta pasta centraliza logs operacionais do projeto.

## Arquivos

- `project.log`: eventos gerais, deploys, tarefas concluídas.
- `backend.log`: logs de API, migrações, seeders e jobs do backend.
- `frontend.log`: logs de build, erros de interface e integrações.
- `security.log`: registros de varreduras e observações de segurança.

## Convenção recomendada

Formato por linha:

`[YYYY-MM-DD HH:mm:ss] [NIVEL] Mensagem`

Exemplo:

`[2026-05-07 09:00:00] [INFO] Backend iniciado em http://localhost:3000`
